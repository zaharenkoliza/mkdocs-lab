# О работе

## Цель

Освоить процесс создания, сборки и автоматического развёртывания статического сайта.

## Основные этапы

1. Настройка Python и виртуального окружения.
2. Установка генератора MkDocs.
3. Создание структуры сайта.
4. Проверка локальной сборки.
5. Размещение исходного кода в Git-репозитории.
6. Настройка CI/CD.
7. Публикация сайта.
8. Проверка корректности развёртывания.
