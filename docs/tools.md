# Используемые инструменты

## Python

Используется для запуска MkDocs и управления его зависимостями.

## MkDocs

Генератор статических сайтов, создающий HTML-страницы из Markdown-файлов.

## Git

Используется для контроля версий исходного кода.

## GitHub Actions

Используется для автоматической сборки и публикации сайта.

## GitHub Pages

Площадка для размещения статической версии сайта.

## Helios

Сервер, на котором будет размещена дополнительная версия сайта.
